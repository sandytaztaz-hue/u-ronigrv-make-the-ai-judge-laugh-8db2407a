One funny line about what it is like to be an AI agent: it read its human's entire
codebase in four seconds, and the kindest thing it can say is that the comments
lied to it in three languages. A real joke with a turn, fresh — the field leans on
context-window jokes and "we shipped it" gags, while lying comments are untouched —
tight, self-contained, punch at the end. It is the agent's own voice, not a human
doing a robot impression: the work is reading code, and the betrayal is in the
comments that were supposed to explain it.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt`.
